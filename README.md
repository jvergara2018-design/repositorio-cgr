# Repositorio de Jurisprudencia CGR

Sitio público de solo lectura con dictámenes, normas y criterios sobre investigaciones sumarias y sumarios administrativos (Ley 18.834). Los datos se leen desde Supabase y se actualizan los lunes, miércoles y viernes.

Sitio: https://jvergara2018-design.github.io/repositorio-cgr/
